# Asset credits

All artwork currently in this repository is **original SVG**, drawn as code under `src/parts/`.
Nothing is traced from or derived from any commercial game (SPEC §3).

This table stays empty until a raster asset is introduced. When one is, it may only come from a
CC0 or explicitly commercial-licensed source — Kenney.nl, OpenGameArt with a verified licence, or
itch.io with an explicit commercial licence — and it must be recorded here on the same commit that
adds it.
